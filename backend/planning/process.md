**第 3 步：整理正文块，并增加按需读取能力。**

建议新增一个集中处理资料的文件：

```text
backend/planning/document_reader.py
```

先提供三项能力：

| 能力 | 作用 |
|---|---|
| 读取正文 | 获取指定页或正文块 |
| 读取补充结构 | 必要时查看标题版式等线索 |
| 查看页面图像 | 必要时渲染指定原始页 |

正文按自然结构整理为段落、列表、表格、代码块，并分配稳定的来源编号。

例如：

```text
document 7 → page 4 → block 3
```

模型后续引用编号，程序负责找到原文，无需模型复制大段内容。

这里的正文块只是读取和引用单位，**不会自动成为学习单元**。长段落或代码需要分批读取时，也不能因此创建新章节。

字号、加粗和 `bbox` 暂不作为必需输入。

**验收结果：** 正文内容没有遗漏，来源编号能够准确定位；读取工具不能访问其他课程的资料。

**第 5 步：建立整份文件概览，并选择分析方式。**

开始调整：

```text
backend/planning/material_analysis.py
```

保留统一分析入口，逐步替换内部逻辑。

模型先接收整份文件的概览：

- 文件主题。
- 已有标题与内容范围。
- 主要正文线索。
- 文字不足的页面。
- 当前使用的粗粒度划分规则。

短文件能够放入上下文时，可以直接提供完整正文。

模型需要判断：

1. 整份作为一个单元是否合适。
2. 是否存在可靠的大板块。
3. 哪些标题只是当前页标题、列表或实验步骤。
4. 哪些地方需要补充读取。

输出简短的判断依据和来源，不要求冗长解释。

**验收结果：** 第一页已有教学内容时不会被丢弃；短文件不会因为存在多个小标题就被自动拆细。

**第 6 步：生成候选学习单元。**

按照以下顺序组织：

```text
已有大板块
→ 内容连贯性
→ 是否明显过大、过杂
→ 是否确实需要拆分
```

候选单元先包含：

```text
英文标题
学习目标
主要概念
原始页面及正文块来源
划分依据
待解决问题
```

此时先不正式发布，也不急着填写最终估时。

候选报告分别保存 `scopes`、`auxiliary_pages`、`excluded_pages`、`pending_ranges` 和 `next_reads`。辅助页不参与单元概念提取；完整页码覆盖不代表主要教学内容已完整覆盖。

需要重点避免：

- 一个概念一个单元。
- 一个标题一个单元。
- 一个编号步骤一个单元。
- 一个读取批次一个单元。
- 因为页数超过某个值就机械拆分。

**验收结果：** L1 能优先保留基础内容和市场术语两个主要范围；Workshop 能保留完整操作目标。

**第 7 步：接入按需补读，并限制修正过程。**

当模型无法判断时，可以明确请求：

```text
读取相关正文
读取相邻内容
查看指定页图像
```

程序检查请求是否合法，执行后把结果返回模型。

前序页面角色和归属理由都属于待核对假设。涉及相邻单元边界时，对比两侧实际教学并分别引用已读取的来源；单页的比较结论必须与局部修改后的归属一致。局部修改保留未触及的范围和辅助页记录，辅助页改动也会使受影响概念需要更新。

例如：

> 某页没有正文，需要确认它是前一个主题的示例，还是新主题。

同时设置：

- 模型调用和工具调用预算。
- 有限的格式修正次数。
- 有限的内容修正次数。
- 无新信息或重复失败时的停止条件。

这些属于执行控制参数，不用于决定章节长度。

图片工具需要先验证现有 HKU 接口的实际支持情况。无法补齐时，报告具体问题并保留已有候选。

**验收结果：** 文字足够时直接判断；确实不足时选择相关工具；持续无法判断时能够停止。

**第 8 步：核对边界与主要内容覆盖。**

对候选做整体检查，只有发现问题时才针对相关范围修正。

| 检查内容 | 例子 |
|---|---|
| 过度拆分 | 定义、例子和总结被分成多个单元 |
| 错误合并 | 一个单元混入大量不相关内容 |
| 主要内容遗漏 | 某页被引用，但第二个重要主题未体现 |
| 来源错误 | 页码或正文块不属于当前文件 |
| 结构误判 | 封面、目录被当成独立教学单元 |
| 证据不足 | 仅凭图片标题声称已理解图片内容 |

需要分别记录：

- **页面属于哪个单元。**
- **目前有哪些内容依据可供后续练习使用。**

章节归属明确但重要图片内容未被读取时，保留证据限制，不把它写成已提取的知识。

**验收结果：** 每个主要教学范围有明确去向，内容覆盖经过核对，剩余问题被明确记录。

**第 9 步：统一估时。**

单元基本稳定后，再估计时间。

先统一默认口径：

> 阅读并理解该单元，不包含 B 的章节练习时间。

实验操作需要另外说明是否包含实际执行。

估时结合：

- 有效教学内容量。
- 概念密度。
- 公式、推导和代码理解难度。
- 重复内容与连续图示。
- 首次学习或复习。
- 实际操作要求。

你提供的单讲 PPT 授课时间经验用于检查整体量级。出现明显异常时，先核对估时依据，不自动启动拆分、合并循环。

**验收结果：**

- 有明确的估计分钟数、口径和依据。
- 封面与目录不单独产生完整学习时间。
- 重复内容不重复累计。
- 不为了达到 20 分钟虚增时间或强行合并。
- 用部分真实学习计时检查偏差。
