# 主流程

CitePath 是基于课程讲义的学习 agent。学生上传讲义 PDF，系统按章节生成学习计划；学生阅读后做练习，系统批改并给出带页码的解释，再按成绩决定通过或再练一轮。学生也可以针对已上传讲义提问，回答必须带出处页码。

依据是 Group 41 的 CitePath 项目提案。MySQL 保存计划、题目、作答、分数和出处。Milvus 保存讲义片段，供检索。两者都在本机用 Docker Compose 运行。界面用 React 和 TypeScript。后端用 Python，流程用 LangChain 编排。PDF 用 PyMuPDF 解析。

## 目录

```text
CitePath/
  docker-compose.yml     MySQL 和 Milvus
  docs/                  本流程和表结构
  backend/
    ingest/              解析 PDF、切段、写入 MySQL 和 Milvus
    db/                  MySQL 表
    vector/              Milvus 集合
    grading/             选择题比对、简答 80%、章节通过线、最多两轮
    agent/               计划、出题、错题解释、独立问答
    tests/               pytest
  frontend/              上传、计划、答题、解释、报告
  data/                  开发用讲义 PDF
```

## 用户看到的过程

1. 学生上传一份课程 PDF，并用一段话写下学习目标和日期。这段原话先原样保存，上传时不调用 agent API。
2. 系统抽出每一页的章节、原始页码和正文，写入 MySQL。抽不出文字的页标为不可用。有正文的页同时写入 Milvus，用文档编号和页码对应 MySQL 里的原文。
3. 整份讲义入库完成后，系统才允许开始练习。入库未完成时不能出题。
4. 系统读取已保存的学生原话和讲义页，调用 agent API 生成学习计划。计划是一串章节。每章列出概念、要读的页码范围、预计时间和一套混合练习。
5. 学生按计划自行阅读，然后做当前章节的练习。题目混合选择题和简答题。每题记下考查概念、题干、标准答案和来源页。
6. 提交后，选择题与标准选项比对。简答题按等权得分点批改，命中达到 80% 算对，否则算错。章节正确率达到通过线算通过。通过线默认 80%，写在配置里，之后可改。
7. 答错的题用来源页生成解释，并显示页码。答对的题不写补救解释。答错时，该题对应概念标为未掌握。
8. 正确率达到通过线：章节标为通过，并生成章节报告。未达到：针对未掌握的概念再出一套题。第二轮结束后停止，报告两轮分数、尚未掌握的点和出处页。一个章节最多两轮。
9. 学生中途离开时，当前题组和已得分数已写入 MySQL。再次进入时继续同一套题，同一题不重复计分。
10. 独立提问只检索已上传讲义。回答给出文档编号和页码。讲义里没有依据时直接说明，不编造答案。

计划会随练习结果、未完成事项和新加事项更新。

## 批改规则

这些规则由程序判断，并用 pytest 验证：

- 选择题答案与标准选项一致才算对。
- 简答题得分点命中率达到 80% 才算对。
- 章节正确率达到当前通过线才算通过。默认通过线是 80%。
- 每个章节最多两轮。第二轮后必须结束。
- 同一道题只计分一次。重复提交不改变分数。
- 独立提问不改变已有练习分数。

## 开发与评测用的讲义

使用 MIT OpenCourseWare 6.006 Introduction to Algorithms（Spring 2020）的五份讲义。Lecture 2（Data Structures）和 Lecture 3（Sorting）用于开发。Lecture 4（Hashing）、Lecture 6（Binary Trees, Part 1）和 Lecture 8（Binary Heaps）留到评测，不用于调系统。引用保留文档编号和 PDF 原始页码。

## 走通的标准

用 Lecture 2 完成下面几步，即视为主流程成立：

1. 上传 PDF 后，每一教学页在 MySQL 中有页码和正文，抽不出文字的页标为不可用。
2. Milvus 能按内容查回同一页，并带上文档编号和页码。
3. 入库完成前不能开始练习。入库完成后能生成包含章节、概念、页码范围和预计时间的计划。
4. 提交一套题后，选择题和简答题按上面的规则判分，错题解释带有页码。
5. 未达通过线时出现第二套题。第二套结束后不再出第三套，报告里同时有两轮分数。
6. 退出后再进入，看到的仍是同一套未做完的题，已提交的题不会被再计一次分。
